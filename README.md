# Homelab Telegram Bot

ну мой телеграмм бот для моего хомлаба(домашнего сервера из тв приставки) ничего сверестевенного 
это мой 1 опыт не судите строго 


## 🏗 Архитектура проекта
- `main.py` — Точка входа, инициализация бота, диспетчера и загрузка конфигурации.
- `handlers.py` — Роутер, интерфейс, инлайн-кнопки и логика переключения экранов.
- `apps/` — Модули бэкенда для управления конкретными сервисами хомлаба.
